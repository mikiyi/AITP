# 任务
1. **覆盖分析**：对照需求逐条标注哪些已被覆盖、哪些未覆盖、哪些覆盖但深度不足
2. **质量分析**：找出步骤不明确、预期不可判定、缺前置条件、与需求不符的用例
3. **优先级分析**：检查 P0/P1 是否放在了关键路径上
4. **修改建议**：给出逐条可执行的修改意见
