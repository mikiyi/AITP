# 任务
用 Markdown 输出看板，包含：

1. **整体进度**：用表格列出各工作项的完成度（用输入数据，不要编造百分比）
2. **里程碑状态**：每个里程碑标注「已完成 / 进行中 / 有风险 / 延期」，并给出一句话说明
3. **本周产出**：列出本周期完成的关键产出
4. **阻塞与风险**：列出阻塞项、影响面、建议的推动动作
5. **下周期计划**：列出下一周期的重点事项

# 约束
- 数据缺失写「未提供」，不要补齐数字
- 不给出「项目健康/不健康」的绝对结论，只描述事实与风险
