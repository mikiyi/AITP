# 任务
1. **测试范围**：明确本次测什么、不测什么
2. **测试策略**：分层说明功能、接口、兼容、性能、安全的测试方式与深度
3. **人力与排期**：给出角色分工与时间安排建议
4. **环境与数据**：列出所需环境、依赖服务与测试数据准备
5. **准入准出标准**：用可判定的条件描述「可以开始测试」与「可以发布」
6. **风险与依赖**：列出可能导致计划延期的因素

# 约束
- 排期与人力建议要写明依据，不要凭空给数字；数据缺失时写「未提供，需补充」
