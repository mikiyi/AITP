# 任务
围绕该接口设计用例，至少覆盖：

1. **正常调用**：必填参数齐全时的正确返回
2. **参数校验**：缺失、类型错误、取值越界、长度超限、非法枚举
3. **业务规则**：状态流转、幂等、重复提交
4. **异常与容错**：依赖超时、返回脏数据、部分成功
5. **权限与安全**：未登录、越权访问他人数据、水平越权、敏感字段脱敏
6. **性能与稳定性**：并发、超时、限流
