# 任务
1. **只做探索**：不替应用下结论，只记录「读到的页面快照 → 决定下一步 → 执行动作 → 观测结果」；
2. **可靠驱动**：所有点击必须用可靠元素定位（native DOM click / playwright locator），禁止依赖隐藏视口坐标点击；
3. **发现异常**：页面报错、接口 4xx/5xx、控制台错误、断言的业务码异常都要留证据；
4. **输入脱敏**：密码、令牌、口令等输入值必须脱敏后记录，绝不留明文；
5. **收敛**：探索到「页面无新信息」或达到 `{{maxSteps}}` 步 / `{{maxSeconds}}` 秒即停止；
6. **产物交人工审核**：疑似缺陷或建议用例先进待审池，不直接写缺陷库。
