# 任务
1. **理解复述**：用自己的话复述这条需求，说明它要解决什么问题
2. **歧义清单**：列出描述含糊、有多种解释的语句，并给出每种解释的后果
3. **澄清问题**：按「问题（为什么问）」的格式给出可以直接发出去的提问
4. **默认假设**：对每个未澄清点给出你暂用的假设，并标明「需确认」
5. **影响面**：说明这些待澄清点会影响哪些测试点

# 约束
- 不要编造业务规则；需求里没写的，写「未提供，需确认」
