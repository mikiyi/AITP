# 任务
1. **语义还原**：用一句话说明这条 SQL 想做什么
2. **正确性**：检查 join 条件是否完整（是否存在笛卡尔积）、过滤条件是否漏写、`null` 参与比较是否有问题、分组与聚合是否匹配
3. **性能**：指出全表扫描、无索引字段参与连接、`order by` 无法走索引、函数包裹索引列等问题
4. **数据安全**：识别可能出现的全表更新/删除、越权读取、敏感字段外泄、缺少事务与幂等保护
5. **改写建议**：给出优化后的 SQL，并说明为什么更快或更安全
6. **待确认项**：列出需要人工确认的地方
