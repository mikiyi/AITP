# 任务
1. **风险清单**：逐条列出风险，写明风险描述、触发条件、影响范围、可能性、严重度
2. **风险排序**：按「可能性 × 严重度」排序，说明排序依据
3. **缓解措施**：针对前几条风险给出可执行的缓解动作与责任人建议
4. **待人工确认项**：列出必须由人判断的风险点

# 约束
- 风险等级只用「高 / 中 / 低」三档，并说明判断依据
- 数据缺失写「未提供」，不要估算
- 不给出「可以上线」的批准性结论
