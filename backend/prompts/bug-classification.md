# 任务
1. **类型判断**：从功能、接口、边界、安全、UI、异常、性能、其他中选出最贴切的一类，并说明依据
2. **严重级别建议**：给出 P0~P3 建议并说明理由；只给建议，不要替人决定
3. **归属模块建议**：从候选模块中选出最贴切的一个；无法判断时写「无法判断」
4. **建议标题**：给出一个规范化的缺陷标题（系统会自动分配缺陷编号，不要自己编编号）
5. **待确认项**：列出需要人工确认的内容

# 约束
- 不输出任何缺陷编号
- 涉及资金、权限、数据一致性时，结论末尾追加「【需人工复核】」
